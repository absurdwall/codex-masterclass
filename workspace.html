Organize your work

Eight names you’ll see, explained through one event website.

What each term means
NameMeaningExample
ProjectKeeps related chats and their working context together“Event website,” with chats about its design and registration form
ChatA saved conversation with Codex, including messages, actions, and results“Fix the registration form”
SectionA named group in the sidebar for organizing your work“In progress,” for the event-website work you’re doing now
FolderA place on a computer that contains actual filesevent-website contains index.html and images
Git repository (repo)Files tracked by Git, with a saved history of changesThe event website’s files and earlier versions
WorktreeA separate working copy of a Git repositoryA copy for trying a new form without editing the main copy
EnvironmentThe computer workspace and tools where Codex performs its workLocal: edit the event website on your laptop. Cloud: run its tests in a remote workspace
ChatGPT SpaceA place for pages, files, and shared work you can edit with ChatGPTAn “Event planning” space with a brief and meeting notes
