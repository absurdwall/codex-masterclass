01 / The assistant

What is a dot?

A dot is a persistent personal AI assistant in ChatGPT. Give it an ongoing responsibility, then return to the same assistant as the work develops.

It can use relevant context, follow up on unfinished work, and coordinate Work or Codex tasks. You set the goal and boundaries; it brings back results, blockers, and decisions that need you.

Watch OpenAI’s dots introduction · 2:26A short product film on OpenAI’s site, rather than a setup tutorial.

Scheduled Tasks · when

Run a saved procedure

“Every Monday at 9, check these venue proposals and report changes.” The schedule triggers the work; the saved instructions define the job.

dot · what keeps moving

Own the follow-through

“Help me get the workshop ready.” Carry the goal forward, connect new information to it, and surface the next decision.

Scheduled Tasks specify when work runs. A Dot owns what needs to keep moving.

A dot can use a saved schedule as part of the responsibility. These ideas work together.

  • Context: use relevant preferences, sources, and project decisions
  • Follow-through: keep track of unfinished work and respond to changing priorities
  • Coordination: delegate execution to Work or Codex, review results, and bring back what needs attention

“Owns” describes the role you assign. It does not mean perfect automatic memory or unlimited authority. Provide critical context and clear permissions, and review important results.

Technical distinctions behind the mental models
  • dot: one persistent primary dot at launch, with more planned. OpenAI currently describes it as powered by GPT-6 Astra; that is not a promise that every worker is permanently locked to one model. Official guide
  • Grok Bot: named Bots coordinate using one account-shared cloud computer with separate screens. Product architecture
  • Muse: its current per-user cloud environment is distinct from the announced Confidential VM. Do not interpret isolation as a shipped cryptographic zero-access guarantee. Security details
  • Hermes: model-flexible, open-source tooling with persistent profiles, skills, scheduling, and delegated work. Profiles separate agent state, not filesystem permissions. “Build your own” means control and customization; Hermes Cloud is also available.

02 / The documents

What is ChatGPT Space?

Space holds durable working documents: the project’s current state, decisions, evidence, and next steps.

A Page is an editable document. A space groups related Pages and files. Keep the current understanding here so people and agents can resume from something clearer than a long chat history.

Illustrative Page excerpt · after a material update

Workshop / current state

Goal: prepare a workshop for 24 people
Decision: shortlist Venue B, subject to accessibility confirmation
Evidence: linked proposals and comparison, reviewed today
Open question: is step-free access confirmed? The organizer reviews this before booking

When new evidence changes the recommendation, update this Page. Keep the useful conclusion, its reason, and the next action.

Start with one project Page: overview, current state, decisions, open questions, experiments, instructions, and milestones. Add child Pages when details grow. The practical guide gives a reusable structure.

Space is a working record, not an agent message board. Use chats for back-and-forth; save material changes to the Page. Creating a Page does not automatically update it or give every agent its contents.

How they fit together

Chats are where we think. Codex is where we execute. Space is where the project remembers.

This is a workflow analogy. It works when you explicitly save and update Pages and point the next task to them; Space is not automatic agent memory.

Chats & Projects

Discussion and exploration

Ask questions, compare ideas, and organize conversations with their files and instructions.

Work / Codex

Execution and verification

Research, build, test, and produce reviewable results in the chosen environment.

GitHub

Durable code and history

Keep the repository, reviewed changes, and version history as the source for code.

Space

Current project understanding

Keep the plan, decisions, evidence links, and what to do next in maintained Pages.

Your dot can coordinate the work across these places within its access and your instructions. After a meaningful result, ask it to update the relevant Page and link the evidence. At the next handoff, ask the agent to read that Page.

Availability varies by account and workspace. Check access before a live demonstration. Review important results and sharing permissions before acting on them.
