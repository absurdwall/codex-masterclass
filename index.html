Follow Along

Start a pet, schedule a useful update, and prepare a Cloud workspace for a small task.

1. Make a Pet

  1. Open a new chat in Codex. Copy the Pet prompt below and paste it into the message box.
  2. Customize the four bracketed details: name, character, personality, and main color. Then send the prompt to start.
  3. Choose A, B, or C when the concepts appear.
  4. Let the animation continue while we move on. Finishing and installation may take longer than class.
Pet instructions and example →
Read the Pet prompt
@Pet

Help me create and install a Codex Pet.

Character brief:
- Name: [Octopus]
- Character: [a small octopus]
- Personality: [lively]
- Main color: [red]

First, invent and show three distinct visual concepts that suit this character. Choose the directions yourself; don’t use a set of styles I have to pick from. Label them A, B, and C, then pause so I can choose.

After I choose, use my selected concept as the visual reference and create the complete animated pet. Run the required checks, package it, and install it as a Codex Pet. Don’t stop at concept art or a static image. When it’s ready, tell me how to enable it.

2. Create a Scheduled Task

  1. In ChatGPT, open a new chat. Copy the briefing prompt below and paste it into the message box.
  2. Before sending, replace 8:00 AM UTC with your preferred time and named time zone. Check the two-week duration, then send.
  3. Review the assistant’s saved-task confirmation. If it asks a setup question, answer it.
  4. Open Scheduled in the left sidebar. Find the task under Upcoming; open … → Edit → Advanced to check its time zone and confirm timing, destination, and stop date.
  5. Use … → Run now, open the result, and check that it gives the briefing you asked for.

Paste this setup request into a chat, not the Scheduled form’s Instructions field. Success means a saved schedule and a useful test result.

Scheduled Task instructions →
Read the briefing prompt
Name this task “Weekday Learning Brief”.

Create a scheduled task in this chat for every Monday through Friday at 8:00 AM UTC. Run it for the next two weeks, then stop.

Search official announcements, research papers, engineering blogs, and reputable reporting for a concise English briefing on AI, data science, and technology. Include up to three worthwhile items, with at least one substantive article, blog post, or report when available.

Open and read the underlying source. Do not treat a short quote post, link roundup, or social snippet as a full article. For each item, give its accurate title, original author or organization, publication date, content type, direct source link, a two-sentence summary of the main finding, and why it matters. Deliver the briefing in this chat. Compare with earlier results here and avoid repeating items unless there is a material update. Prefer fewer strong items over filler. If nothing worthwhile is new, do not send an update.

If earlier results are unavailable, say so and establish a baseline instead of claiming deduplication. If a required source cannot be checked, report the blocker once instead of claiming nothing changed.

Confirm the saved timing, time zone, destination, and stop date.

3. Create a Codex Cloud environment

Demo task being finalized. Wait for the instructor’s repository, environment setup, and exact task before beginning.

  1. On ChatGPT web, open your profile menu → Settings → Codex Cloud → Environments → Create environment.
  2. In Search repositories, find the agreed repository, tick its checkbox, then click Get started. Connect GitHub if prompted and check repository access.
  3. Answer Codex’s setup questions. Review its setup report, check the verification commands passed, resolve any issues, and save.
  4. Click Publish. Wait for Environment published, then click Start a new task.
  5. Confirm the intended environment is selected. Enter the agreed small task, send it, then review its changed files and test results.

Success means a published environment and a fresh task that passes the agreed checks. Saving a draft alone is not enough.
