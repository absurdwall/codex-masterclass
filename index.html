Follow along

Try three things together

Start a pet, schedule a useful update, and prepare a Cloud workspace for a small task.

1. Make a Pet

  1. Open a new chat with @Pet. Copy the prompt and replace its four bracketed character details.
  2. Choose A, B, or C when the concepts appear.
  3. Let the animation continue while we move on. Finishing and installation may take longer than class.
Pet instructions and example →
Read the Pet prompt
@Pet

Help me create and install a Codex Pet.

Character brief:
- Name: [Octopus]
- Character: [a small octopus]
- Personality: [lively]
- Main color: [red]

First, invent and show three distinct visual concepts that suit this character. Choose the directions yourself; don’t use a set of styles I have to pick from. Label them A, B, and C, then pause so I can choose.

After I choose, use my selected concept as the visual reference and create the complete animated pet. Run the required checks, package it, and install it as a Codex Pet. Don’t stop at concept art or a static image. When it’s ready, tell me how to enable it.

2. Create a Scheduled Task

  1. Copy the Weekday Learning Brief below into a chat.
  2. Before sending, adjust its 8:00 AM UTC time, time zone, and two-week duration to suit you.
  3. After creation, open Scheduled and confirm the saved time, time zone, destination, and stop date.
Scheduled Task instructions →
Read the briefing prompt
Name this task “Weekday Learning Brief”.

Create a scheduled task in this chat for every Monday through Friday at 8:00 AM UTC. Run it for the next two weeks, then stop.

Search official announcements, research papers, engineering blogs, and reputable reporting for a concise English briefing on AI, data science, and technology. Include up to three worthwhile items, with at least one substantive article, blog post, or report when available.

Open and read the underlying source. Do not treat a short quote post, link roundup, or social snippet as a full article. For each item, give its accurate title, original author or organization, publication date, content type, direct source link, a two-sentence summary of the main finding, and why it matters. Deliver the briefing in this chat. Compare with earlier results here and avoid repeating items unless there is a material update. Prefer fewer strong items over filler. If nothing worthwhile is new, do not send an update.

If earlier results are unavailable, say so and establish a baseline instead of claiming deduplication. If a required source cannot be checked, report the blocker once instead of claiming nothing changed.

Confirm the saved timing, time zone, destination, and stop date.
