Choose a model

Balance capability, thinking effort, and cost against the work in front of you.

Three controls: model, effort, and speed

Model = the engine

The model determines the underlying capabilities. A faster, cheaper model may be enough for a narrow edit; a more capable model may help with ambiguous problems.

Effort = room to think

Reasoning effort controls how much reasoning the model can use. Higher effort can improve difficult answers, but usually costs time and tokens. It is not a guarantee of correctness.

Speed = a service tier, not extra intelligence

Fast is a separate control from model and reasoning effort. Where available, Fast supports Luna, Sol, and Astra. It uses 2.5× included subscription usage, or 2× purchased credits / pay-as-you-go usage, versus Standard. Those are usage multipliers, not a promise of 2× or 2.5× speed. It does not guarantee faster tools or image generation.

Speed guide
Model ≠ product

Codex and Claude Code are agent products. GPT and Claude are model families. Product tools, prompts, context, permissions, and model routing all affect the result. An API benchmark is not an end-to-end product ranking.

What I would start with

Practical course recommendations. Check the result against your own requirements; these are not universal rankings.

The everyday starting point

GPT-6.1 Sol medium. A strong cost/capability balance in this snapshot: 48 points at $0.21. Start here for a scoped feature or multi-step task with clear acceptance criteria.

More reasoning without a big-model jump

GPT-6.1 Sol xhigh. 51 points at $0.39. Try it when medium misses a specific edge case, after checking that the prompt includes the needed context and tests.

When the harder problem earns it

Opus 5.5 medium, then max if needed. Medium scores 51 at $1.34; max reaches 58 at $5.98. Use the extra spend only when a cheaper configuration fails your acceptance criteria.

Choose the whole workflow, not just the score

Luna max is the budget comparison here; Sonnet, Astra, Gemini, and Grok may fit different tools and workflows. The table measures model configurations through one benchmark harness, not the full Codex, Claude Code, or other app experience.

Choose from the options available in your account. In Claude Code, /effort changes effort. In Codex, treat model, effort, and speed as separate choices.

Does a $100 plan include $100 of API usage?

No fixed conversion. A subscription buys app access and a usage allowance. API billing meters tokens and tools. The same monthly spend buys a different thing.

At $20 / month

ChatGPT Plus and Claude Pro are subscription examples at this price. Their included usage is not a $20 API credit balance; the amount of work depends on the models, task size, and plan limits.

At $100 / month

ChatGPT Pro100 offers a larger allowance. Claude Max 5x offers five times Pro’s per-session allowance, with weekly limits. Neither means a fixed $100 of API credits.

The useful comparison: how much verified work did you complete for the fee? Look at actual usage rather than guessed message counts. Claude Code’s API-equivalent cost estimate can help with hindsight, but it is not a subscription bill.
