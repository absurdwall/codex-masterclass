Codex Cloud: keep working while your laptop sleeps

Codex Cloud runs coding tasks on OpenAI’s computers. It can read your GitHub project, edit code, and run tests while you do something else.

Use it for a bug fix, a small feature, or a test run that can work in the background. You review the changed files and test results afterward.

Set it up once

A cloud environment is your project’s saved setup: its repositories, dependencies, and tools.

  1. Create an environment. Open Settings → Codex Cloud → Environments → Create environment on web or desktop.
  2. Choose your project. Select a GitHub repository, connect GitHub if asked, then click Get started. Codex prepares the tools and tests the setup.
  3. Check and publish. Answer any setup questions, review the results, and resolve failures. Save, then click Publish.
  4. Start a task. When Environment published appears, click Start a new task and describe the job. Next time, choose Work in → Cloud and select this environment.
