Topic 05 · Optional practice and reference

Scheduled tasks: set up, test, repeat

Three copyable exercises for useful recurring work with fewer noisy updates.

In the sessionSetup and exercises

Start with one job: a weekday brief, a weekend read, or a price alert. Test it once before saving the schedule. These examples adapt real recurring workflows; change the UTC times, limits, and trial durations to fit your needs.

What a scheduled task does

A scheduled task saves a job to run later or repeatedly. It can search, analyze, and produce an output using the context and tools available to that task. A reminder tells you to do something; a scheduled job can do the permitted work and bring back the result.

Use it for

A recurring briefing, a source check, a periodic report, or an alert that only matters when a condition changes.

Decide what a useful update looks like

Specify the source, timing, time zone, output, notification rule, and a stopping date. “Check regularly” leaves too much undecided.

Official: Scheduled tasks

Know where it runs and what context it gets

ChoiceWhat changes
Local project taskThe required computer must be on and the app running. The task uses the available local project and tools.
Cloud taskUses accessible uploaded context and connected tools. It does not directly gain access to a folder on your laptop.
Task in an existing chatReuses that chat’s context. These exercises request results in the same chat so earlier reports can be checked.
Standalone taskStarts a new chat for each run. Do not assume the new chat has every previous report.

Scheduled management is available on web and desktop, not as the same management screen in the CLI or IDE. Account, tool, and workspace availability still apply.

Exercise 1

Weekday learning brief

A small daily habit: at most three useful items, without repeated links.

Read and copy the full prompt
English prompt · customize before submitting
Name this task “Weekday Learning Brief”.

Create a scheduled task in this chat for every Monday through Friday at 8:00 AM UTC. Run it for the next two weeks, then stop.

Search official announcements, research papers, engineering blogs, and reputable reporting for a concise English briefing on AI, data science, and technology. Include up to three worthwhile items, with at least one substantive article, blog post, or report when available.

Open and read the underlying source. Do not treat a short quote post, link roundup, or social snippet as a full article. For each item, give its accurate title, original author or organization, publication date, content type, direct source link, a two-sentence summary of the main finding, and why it matters. Deliver the briefing in this chat. Compare with earlier results here and avoid repeating items unless there is a material update. Prefer fewer strong items over filler. If nothing worthwhile is new, do not send an update.

If earlier results are unavailable, say so and establish a baseline instead of claiming deduplication. If a required source cannot be checked, report the blocker once instead of claiming nothing changed.

Confirm the saved timing, time zone, destination, and stop date.

Check the result: Check that the first report has no more than three items, real source links, dates, and a reason to care. On the next run, inspect whether it repeats an unchanged item.

Exercise 2

One exceptional weekend read

A weekly recommendation with a high quality bar, rather than a long list.

Read and copy the full prompt
English prompt · customize before submitting
Name this task “One Exceptional Weekend Read”.

Create a scheduled task in this chat for Saturdays at 9:00 AM UTC. Run it for four Saturdays, then stop.

Find one exceptional article or essay published in the previous 14 days about AI, technology, science, psychology, or learning. Prefer free access; if a paywalled piece is clearly strongest, label it.

Give the title, author, publication date, access status (free or paywalled), direct source link, a short summary, and three reasons it is worth reading. Deliver the recommendation in this chat. Check earlier results here and do not recommend the same piece twice. Choose quality over length or popularity. If no new article meets the standard, do not send an update.

If earlier results are unavailable, say so and establish a baseline instead of claiming deduplication. If a required source cannot be checked, report the blocker once instead of claiming nothing changed.

Confirm the saved timing, time zone, destination, and final run.

Check the result: Open the recommended article. Is it recent, useful, and worth your time? A skipped week is better than a weak recommendation.

Exercise 3

Quiet monitor deal watch

A conditional alert: frequent checking should not mean frequent messages.

Read and copy the full prompt
English prompt · customize before submitting
Name this task “Quiet Monitor Deal Watch”.

Create a scheduled task in this chat at 00:00, 06:00, 12:00, and 18:00 UTC each day for the next seven days, then stop.

Check Amazon and Walmart for exceptional deals on new 27-inch 4K monitors with at least 120 Hz and an OLED or high-spec mini-LED panel. Use $500 as the maximum item price. Verify the exact model, specifications, seller, availability, shipping charges, and any available price history. Do not treat an inflated list-price discount as proof of value.

Alert me in this chat only when a matching product is within the price limit and unusually good value. Include the exact model and key specifications, price, seller, direct product link, shipping information, and why it qualifies. Compare with earlier alerts here; do not repeat an alert unless the price, seller, bundle, or availability materially improves. Otherwise do not send an update. Do not buy anything.

If earlier alerts are unavailable, say so and establish a baseline instead of claiming deduplication. If a required source cannot be checked, report that blocker once instead of claiming there were no deals. Confirm the saved timing, time zone, destination, and stop date.

Check the result: Check the actual listing and seller. Item price is not the checkout total; shipping and tax can change what you would pay. A missing alert is not evidence that all retailers were checked.
