What is a Codex Pet?

A Pet is an optional animated companion that follows your work. Choose a built-in or custom character in Settings → Pets. Try moving your pointer around the Octopus above.

1. Make a Pet

Replace the four bracketed details. Let the model propose the visual styles; choose A, B, or C when it pauses.

  1. Open a new chat in Codex. Copy the Pet prompt below and paste it into the message box.
  2. Customize the four bracketed details: name, character, personality, and main color. Then send the prompt to start.
  3. Choose A, B, or C when the concepts appear.
  4. Let the animation continue while we move on. Finishing and installation may take longer than class.
Workshop prompt · use @Pet
@Pet

Help me create and install a Codex Pet.

Character brief:
- Name: [Octopus]
- Character: [a small octopus]
- Personality: [lively]
- Main color: [red]

First, invent and show three distinct visual concepts that suit this character. Choose the directions yourself; don’t use a set of styles I have to pick from. Label them A, B, and C, then pause so I can choose.

After I choose, use my selected concept as the visual reference and create the complete animated pet. Run the required checks, package it, and install it as a Codex Pet. Don’t stop at concept art or a static image. When it’s ready, tell me how to enable it.

2. Create a Scheduled Task

  1. Choose one of the three real tasks below. Adjust the schedule and edit its full prompt.
  2. Click Copy prompt, paste it into a new ChatGPT chat, and send. This is a setup request for chat, not the Scheduled form’s Instructions field.
  3. Open Scheduled, confirm its timing and time zone, then use … → Run now and review the result.

The reset watch includes its original saved baseline; check and update that date before using it.

3. Create a Codex Cloud environment

Demo task being finalized. Wait for the instructor’s repository, environment setup, and exact task before beginning.

  1. On ChatGPT web, open your profile menu → Settings → Codex Cloud → Environments → Create environment.
  2. In Search repositories, find the agreed repository, tick its checkbox, then click Get started. Connect GitHub if prompted and check repository access.
  3. Answer Codex’s setup questions. Review its setup report, check the verification commands passed, resolve any issues, and save.
  4. Click Publish. Wait for Environment published, then click Start a new task.
  5. Confirm the intended environment is selected. Enter the agreed small task, send it, then review its changed files and test results.

Success means a published environment and a fresh task that passes the agreed checks. Saving a draft alone is not enough.
