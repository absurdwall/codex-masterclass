What is a Codex Pet?

A Pet is an optional animated companion for following your work. In the desktop app, it can float above other windows, show task activity, and offer controls to start a chat by typing or speaking. A custom Pet changes the character’s appearance, not the model’s capabilities.

Choose a built-in or custom Pet in Settings → Pets. The floating desktop companion and the pet shown in a supported web chat have different controls.

The workshop prompt

Replace the four bracketed details. Let the model propose the visual styles; choose A, B, or C when it pauses.

Workshop prompt · use @Pet
@Pet

Help me create and install a Codex Pet.

Character brief:
- Name: [Octopus]
- Character: [a small octopus]
- Personality: [lively]
- Main color: [red]

First, invent and show three distinct visual concepts that suit this character. Choose the directions yourself; don’t use a set of styles I have to pick from. Label them A, B, and C, then pause so I can choose.

After I choose, use my selected concept as the visual reference and create the complete animated pet. Run the required checks, package it, and install it as a Codex Pet. Don’t stop at concept art or a static image. When it’s ready, tell me how to enable it.
Start with @Pet

Choose @Pet in the composer, then paste the prompt. If it is unavailable, check your app’s Pets or plugin controls before following along.

Suggested rehearsal setting: Luna Medium; Fast optional

Rehearse this setting first; it is not a proven best choice. Fast uses more allowance and may not speed up image generation or tools. Finishing the animation may take longer than this lesson. We will show a prepared example while generation continues.

Run the exercise

  1. Paste the prompt in a new creation chat.

    Use @Pet and change only the four character details. Keep the rest of the request together.

  2. Choose A, B, or C.

    If the images or labels are unclear, ask which concept each image represents before choosing. Give one reason for your choice.

  3. Inspect the finished animation before enabling it.

    Check that the character stays consistent as it moves. Ask for the validation results and installation instructions. You can complete this step after class.

Make feedback concrete

Hard to act on

“Make it better.”

This leaves the model to guess which part you dislike.

Specific and reviewable

“Keep the colors and round silhouette. Make the eyes larger so they read clearly at small size. Keep the movement gentle.”

This is an example refinement, not a replacement for the workshop prompt.

Try it · 1 minute

Your pet looks good still, but changes shape while moving. What should you ask for?

Compare your answer

Ask to preserve the character’s proportions and defining details across animation frames. Keep the palette and overall design fixed, then inspect the updated movement rather than requesting a complete redesign.
