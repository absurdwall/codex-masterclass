What is a Codex Pet?

A Pet is an optional animated companion for following your work. In the desktop app, it can float above other windows, show task activity, and offer controls to start a chat by typing or speaking. A custom Pet changes the character’s appearance, not the model’s capabilities.

Choose a built-in or custom Pet in Settings → Pets. The floating desktop companion and the pet shown in a supported web chat have different controls.

Make, inspect, refine

This exercise practices a complete creative loop: use the prepared prompt, inspect the generated pet, and make one precise improvement. The live session focuses on the concept-selection checkpoint and a prepared installed example. Following along is optional; finishing an animated pet during the session is not required.

1

Start with intent

Know the character, visual style, and defining features before generating.

2

Look at the result

Check the actual preview. A description of success is not the same as a usable pet.

Change one thing

The workshop prompt

Replace only the four bracketed character details. The model invents three distinct directions, labels them A, B, and C, then pauses for your choice. These are not three styles you must preselect.

Workshop prompt · use @Pet
@Pet

Help me create and install a Codex Pet.

Character brief:
- Name: [Octopus]
- Character: [a small octopus]
- Personality: [lively]
- Main color: [red]

First, invent and show three distinct visual concepts that suit this character. Choose the directions yourself; don’t use a set of styles I have to pick from. Label them A, B, and C, then pause so I can choose.

After I choose, use my selected concept as the visual reference and create the complete animated pet. Run the required checks, package it, and install it as a Codex Pet. Don’t stop at concept art or a static image. When it’s ready, tell me how to enable it.
Start with @Pet

Use @Pet in the composer to choose the pet tool available in your app, then paste the prompt. You do not need to name an internal skill in the request. If the tool is not available, check your app’s Pets or plugin controls before following along.

Suggested rehearsal setting: Luna Medium; Fast optional

This is a candidate to rehearse, not a validated best setting. Higher speed has a usage trade-off and does not guarantee faster image generation or tool execution. A previous pet run took much longer than the live exercise, so the session does not promise completion within 20 minutes.

Run the exercise

  1. Open a focused creation chat.

    Use the pet-creation workflow available to your account. Keep the prepared prompt together with the four character details. Follow along only if your setup is ready.

  2. Run the prepared prompt.

    Only change the fields the instructor identifies. Keep the structural requirements intact.

  3. Choose A, B, or C at the pause.

    Check that three concepts are clearly labeled. If extra images or unclear labels appear, ask which image corresponds to A, B, and C before choosing. Explain one reason for your choice.

  4. Continue toward the complete animated pet.

    The selected concept is the reference. The requested finish includes animation, checks, packaging, installation, and instructions to enable it. Inspect consistency and movement, not just the concept image.

  5. Choose and activate.

    The presenter can show the prepared installed example while generation continues. Students can complete the same process after the session. Before activating your own result, inspect the preview and the reported checks.

Make feedback concrete

Hard to act on

“Make it better.”

This leaves the model to guess which part you dislike.

Specific and reviewable

“Keep the colors and round silhouette. Make the eyes larger so they read clearly at small size. Keep the movement gentle.”

This is an example refinement, not a replacement for the workshop prompt.

Try it · 1 minute

Your pet looks good still, but changes shape while moving. What should you ask for?

Compare your answer

Ask to preserve the character’s proportions and defining details across animation frames. Keep the palette and overall design fixed, then inspect the updated movement rather than requesting a complete redesign.
